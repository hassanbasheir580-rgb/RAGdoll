# RAGdoll Roadmap

This roadmap outlines the planned development milestones for RAGdoll. Features will be implemented incrementally, with each phase building upon the previous one.

---

## Phase 1 – Project Foundation

- [ ] Create project structure
- [ ] Set up React frontend
- [ ] Set up Express backend
- [ ] Set up FastAPI AI service
- [ ] Configure communication between services
- [ ] Configure development environment

---

## Phase 2 – Document Processing

- [ ] Upload PDF documents
- [ ] Store uploaded files
- [ ] Extract text from PDFs
- [ ] Preserve page numbers
- [ ] Validate supported file formats

---

## Phase 3 – Retrieval Pipeline

- [ ] Split extracted text into chunks
- [ ] Generate vector embeddings
- [ ] Store embeddings in ChromaDB
- [ ] Implement semantic similarity search
- [ ] Retrieve relevant document context

---

## Phase 4 – AI Responses

- [ ] Integrate language model
- [ ] Build retrieval-augmented prompt pipeline
- [ ] Generate grounded responses
- [ ] Return source citations with page references
- [ ] Handle follow-up questions

---

## Phase 5 – User Experience

- [ ] Chat interface
- [ ] Document management dashboard
- [ ] Conversation history
- [ ] Multiple document support
- [ ] Delete uploaded documents
- [ ] Loading and error states

---

## Phase 6 – Deployment

- [ ] Deploy frontend
- [ ] Deploy backend
- [ ] Deploy AI service
- [ ] Configure production environment
- [ ] Final testing and documentation

---

## Future Enhancements

- Support Microsoft Word documents
- Support Markdown files
- OCR for scanned PDFs
- Document collections
- User authentication
- Shared workspaces
- Streaming AI responses
- Search across multiple document collections

# RAGdoll

An AI-powered document assistant that helps users understand and interact with their documents through natural language.

## Overview

RAGdoll is a Retrieval-Augmented Generation (RAG) application that allows users to upload documents and ask questions about their content. Instead of relying solely on a language model's general knowledge, RAGdoll retrieves relevant information from uploaded documents to generate accurate, context-aware responses with source citations.

The project is being built as a learning experience in modern AI application development, combining full-stack software engineering with large language models, vector databases, and semantic search.

## Planned Features

- Upload and manage documents
- Ask questions in natural language
- Semantic search using vector embeddings
- Source citations for every response
- Support for multiple documents
- Conversation history
- AI-generated document summaries
- Clean and responsive user interface

## Why RAGdoll?

Large language models are powerful, but they cannot reliably answer questions about documents they have never seen. RAGdoll bridges that gap by retrieving the most relevant sections of uploaded documents before generating a response, resulting in more accurate and trustworthy answers.
